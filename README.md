# Lumivey

> **Lumivey begrijpt ondernemers voordat zij websites bouwt.**

---

# Welkom

Lumivey is geen traditionele websitebouwer.

Lumivey is een Discovery Engine die ondernemers helpt hun digitale aanwezigheid te ontwikkelen vanuit herkenning, identiteit en vertrouwen.

Een website is geen doel.

Een website is de eerste tastbare uitkomst van een goed begrip van de ondernemer.

---

# Repositories

De ontwikkeling van Lumivey is verdeeld over meerdere repositories.

## lumivey-chat

De hoofdrepository.

Hier wordt Lumivey ontwikkeld.

Deze repository bevat de architectuur, kennis en implementatie van de Discovery Engine.

## lumivey-api

Ondersteunende repository.

Bevat API's, technische experimenten en integraties.

De architectuur wordt niet vanuit deze repository bepaald.

# Quiet Web

Quiet Web is geen functie.

Quiet Web is het karakter van Lumivey.

Daarom geldt altijd:

* rust boven snelheid
* eenvoud boven complexiteit
* begrijpen vóór bouwen
* erkenning vóór volledigheid
* geen AI-show
* geen marketingtrucs
* geen overbodige vragen

Iedere ontwerpbeslissing wordt hieraan getoetst.

# Tot slot

Lumivey is geen project dat eindigt na oplevering.

Lumivey blijft leren.

Iedere fout is leerdata.

Iedere klantvraag is een signaal.

Iedere verbetering wordt getoetst aan:

* Het Wat
* De Wetten
* Runtime Core
* Quiet Web

Zo blijft Lumivey groeien zonder haar identiteit te verliezen.
